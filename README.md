# 考研学习台

本地优先、可配置的心理学考研学习与择校辅助平台。默认面向 312 心理学专业基础，可从择校、定专业、基础复习一直覆盖到报名、初试和复试。

学习记录只保存在当前浏览器，不需要账号，也不会上传个人学习数据。院校、专业、考试日期、官方来源、阶段流程和计划文件均由配置文件驱动。

## 功能

- 冲稳保目标管理，可切换当前目标。
- 从择校到复试的五阶段备考流程。
- 九科教材章节进度、原创习题、错题本和记忆闪卡。
- 番茄钟、每日打卡、学习笔记和手动补记。
- 学习档案、趋势图、热力图、周复盘、科目正确率和薄弱点分析。
- 学习成绩单 PNG、学习记录 CSV、JSON 备份与恢复。
- 资料采集、分类检索、收藏和已读管理。
- 浅色与黑夜模式，桌面和手机布局。

## 快速开始

需要 Node.js 20 或更高版本，无需安装第三方依赖。

```bash
npm run build
```

然后直接用浏览器打开生成的 `dashboard.html`。

也可以运行：

```bash
npm start
```

该命令同样只生成页面，不会启动 Web 服务器。

修改配置或学习内容后，可运行发布前检查：

```bash
npm test
```

检查会验证配置引用、题库答案、阶段任务和生成页面是否包含本机路径或个人院校信息。

## 配置自己的目标

首次使用时先修改 `config.json`。仓库同时提供 `config.example.json` 作为结构参考。

主要配置项：

| 配置 | 作用 |
| --- | --- |
| `app` | 应用名称、标签、简介和导出文件前缀 |
| `profile` | 考试年份、院校、专业代码、考试科目、计划初试日期和时区 |
| `targets` | 冲刺、稳妥、保底院校及当前目标 |
| `workflow` | 备考阶段、起止偏移天数、阶段目标和任务 |
| `officialSources` | 官方报考信息和课程资源来源 |
| `curatedResources` | 精选资源，采集时优先处理 |
| `searchQueries` | 自动检索关键词 |
| `planFiles` | 总览页展示的学习计划文件 |
| `collector.catalog` | 可选的招生专业目录页面 |
| `rules` | 请求超时、采集间隔和单次采集上限 |

修改配置后重新运行：

```bash
npm run build
```

阶段日期根据 `profile.examDate` 和 `workflow` 中的 `startOffsetDays`、`endOffsetDays` 自动计算。负值表示考试前，正值表示考试后。

## 修改学习内容内核

学习内容位于 `study-data.mjs`，可以直接增删改：

- `subjects`：科目、教材、章节、权重和学习资源。
- `questions`：原创题库。
- `flashcards`：记忆闪卡。
- `milestones`：关键节点，使用 `offsetDays` 相对考试日期。
- `planTasks`：阶段任务，`phase` 对应 `config.json` 中的 `planPhase`。

修改后重新构建即可。默认内容适合作为模板，不构成任何院校的官方参考书单或报考结论。

## 资料采集

```bash
npm run collect
```

采集结果写入：

- `data/articles.json`：结构化资料。
- `knowledge-base/`：Markdown 知识库和更新日报。
- `data/state.json`：已采集链接状态。
- `data/errors.json`：最近一次运行错误。

采集器仅访问 `config.json` 中配置的来源。若需要解析目标院校的专业目录，填写 `collector.catalog.url`；留空则跳过目录采集。不同院校页面结构差异较大，目录页目前以正文摘录方式保存，招生人数、科目和复试要求仍应人工核对。

仓库不包含定时任务。需要自动更新时，可自行使用系统计划任务定时运行 `npm run collect && npm run build`。

## 数据与隐私

- 学习进度、笔记、打卡和答题记录保存在浏览器 `localStorage`。
- 清理浏览器数据或更换设备前，请在“学习工具”中导出 JSON 备份。
- 采集到的公开资料会保存在本地 `data/` 和 `knowledge-base/` 中。
- 公开发布自己的仓库前，不要提交个人学习记录、备份文件、私人资料或真实院校调研底稿。
- `dashboard.html` 是生成文件，可以随仓库发布，方便直接预览。

## 使用边界

招生简章、专业目录、分数线、报名时间和考试安排可能变化。所有政策信息应以目标院校研究生院、学院官网和研招网当年正式文件为准。第三方经验帖仅用于获取复习方法，不能作为报考依据。
