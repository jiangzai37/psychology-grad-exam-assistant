# 备考学习台知识库

> 本地公开资料库。考试、机构、年份和分类以 `config.json` 为准。

## 分类入口

- [官方考试信息](./官方考试信息.md)
- [备考知识](./备考知识.md)
- [目标与机构动态](./目标与机构动态.md)
- [经验与课程资源](./经验与课程资源.md)

## 使用原则

1. 考试科目、报考条件、时间节点和相关安排，只认考试机构与官方平台的当前正式文件。
2. 第三方经验帖用于获取学习方法，不直接作为政策依据。
3. 每条资料保留来源链接和采集日期；内容冲突时，以官方最新公告为准。
4. 考试信息变化后，重新核对范围、日期、条件和资料版本。
5. 运行 `npm run collect` 后，本页和分类页会自动更新。
