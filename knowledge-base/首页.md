# 312 心理学考研知识库

> 本地资料库。默认面向 312 心理学专业基础，院校、年份和考试日期以 `config.json` 为准。

## 分类入口

- [官方报考信息](./官方报考信息.md)
- [312 备考知识](./312%20备考知识.md)
- [院校与导师动态](./院校与导师动态.md)
- [经验帖与课程资源](./经验帖与课程资源.md)

## 使用原则

1. 招生人数、考试科目、复试科目、报考条件和时间节点，只认目标院校研究生院及研招网当年正式文件。
2. 第三方经验帖用于获取复习方法，不直接作为政策依据。
3. 每条资料保留来源链接和采集日期；内容冲突时，以官方最新公告为准。
4. 运行 `npm run collect` 后，本页和分类页会自动更新。
